# Decisions Log

Decisions made autonomously while the owner was away. Each can be revisited.

- **D-001 Stack**: TypeScript + Vite + three.js (WebGL2) + React for UI overlays. WebGL2 over WebGPU for laptop/browser compatibility.
- **D-002 Original IP**: All parts, art, names original. Agency name in-game: "Web Space Program". Crew are humans ("astronauts"), not a mascot species.
- **D-003 Scale**: Real data is the source; `s` scales lengths, GM by s² (preserves surface gravity), the atmosphere profile is compressed vertically by s^0.3 (standard → Earth atmosphere ≈ 70 km, like the genre classic), rotation periods by s^0.5. Default preset `standard` s=0.1. `real` preset uses exponent 1 for everything.
- **D-004 Rigid vessels**: Vessels are single rigid bodies (no wobbly joints). Structural failure via load thresholds. Removes KSP's "Kraken" class of bugs.
- **D-005 Gravity**: Patched conics for prediction and on-rails; physics mode uses dominant-body gravity, with optional n-body perturbations later.
- **D-006 Launch site**: Cape Canaveral-ish latitude (28.5°N) on Earth, east coast. Named "Coastal Launch Complex".
- **D-007 Autopilot building blocks** (`src/game/autopilot.ts`): planners (circularize, transfer to child/parent body, course correction) add maneuver nodes; controllers (ascent, node execution, powered landing) return a `ControlInput` per frame plus an optional `coastUntil` UT so any driver (tests now, an in-game autopilot later) can rails-warp idle phases. Node burns track remaining dv from measured proper acceleration and, for prograde/retrograde burns, stop on the planned orbital energy (finite-burn losses otherwise wreck near-escape burns like TLI). Landing = predictive suicide burn + slope-aware terminal descent (diverts to ground under ~8°). `tests/world-moon.test.ts` flies the stock Selene lander Earth → Moon landing → back into Earth's SOI with no balance changes.
- **D-008 Terrain relief**: relief scales by s^0.8 (standard: 0.16×) — slightly exaggerated vs radii for drama, but lunar slopes stay landable.
- **D-009 Tracking Station warp**: tracking uses the existing active-vessel warp clamps and encounter stops through `World.tick`; fleet focus is independent of the simulation's active vessel. With no active vessel, `advanceRailsTo` packs and propagates unattended vessels using existing rails event rules. Fleet conics refresh at 2 Hz while icon positions and floating-origin transforms update every frame.
- **D-010 Interplanetary targeting**: `src/game/interplanetary.ts` searches a scaled-ephemeris Lambert departure/flight-time grid, minimizes estimated ejection plus circular capture cost (capture optional), resolves the actual parking-orbit ejection plane and phase, and refines time/prograde/normal/radial against Earth → Sun → target patched conics. Prograde transfers with no complete extra revolutions only; exactly collinear Lambert endpoints are rejected as plane-ambiguous. Moon departure requires first reaching a planetary parking orbit. Ringrunner uses existing chemical engines and tanks, with no part balance changes; small late cruise trims are required because finite burns leave sub-m/s errors that matter over years. `porkchopGrid` exposes pure data for future UI work. The synchronous planner currently takes a few seconds; a worker is deferred.
- **D-011 Crew / EVA**: Crew are original human astronauts, generated from a persisted integer seed. Roster IDs live on command `PartState`s so staging and docking UID remaps preserve assignments. Catalog pod dry mass includes occupied seats (100 kg per suited astronaut); empty seats subtract that mass, preserving stock launch balance. EVA uses a runtime-only `eva-astronaut` part (95 kg dry + 5 kg monopropellant) and a dedicated DOM-free character step in the existing vessel/rails system. Hatch transfer preserves combined COM and linear momentum, with no separation impulse. Ground speed is 1.4 m/s walking / 3.5 m/s running, hop 2.5 m/s, slope limit 45°. Jetpack thrust is 35 N with 600 m/s exhaust velocity (~30.8 m/s total Δv). Boarding within 3 m of a free hatch and below 3 m/s relative speed services/refills the suit from abstract cabin supplies. Enter boards, leaving B available for aircraft brakes. Flags are body-fixed surface objects. Empty pods without a probe core accept no flight control or staging. Saves without crew data receive deterministic launch-style assignments on load.
- **D-012 Aircraft**: jets are `EngineModule`s with `airBreathing` (thrust = static thrust × Mach curve × (ρ/1.225)^k × intake-air fraction; fuel-only Isp, liquid fuel only). Intake air is produced every step and never stored (leftovers vented), so starvation at altitude/low speed is immediate; jets flame out below 15 % supply and relight automatically. Wheels are spring/damper suspensions with an impulse tyre model (lateral grip with sticky/sliding μ, rolling resistance, brakes inside a friction circle); steering fades with speed. Editor core now uses the catalogue surface-mount convention (srf node / −Z face); SPH crafts build horizontally (view-only rotation, craft +Y stays the nose) and launch on the runway (`World.launch(craft, 'runway')`, free on their wheels, no clamps).
- **D-013 Science / career**: `World.mode` defaults to `sandbox`; optional `SavedWorld.mode/progression` preserve version-1 saves. Science and career use the same 25-node research tree (foundation + six four-tier paths). Career starts with 60,000 credits; science starts at zero in both modes. A subject is experiment/body/situation plus biome only where that experiment resolves biomes. Recording reserves the next repeat globally (even lost observations consume a repeat); values halve each time, with a finite total of twice the first observation. A vessel can store one observation of each subject at a time. Data lives on the instrument/pod/EVA part, follows splits/docking, and transfers into a pod on boarding. Transmission credits 40% or 65%; Earth recovery credits the remainder, never twice. Antennas currently abstract power, range and line of sight.
- **D-014 Career economy / commissions**: Three seeded contract kinds: stable orbit, surface expedition with Earth hardware recovery, and biome-dependent science. Maximum three active, 20 Julian years to finish. Each offer pays an advance; failure/abandonment deducts a larger penalty. Surface provenance follows parts, so recovering unrelated Earth hardware cannot satisfy a return contract. Advances/rewards/penalties are 2,000/10,000/3,000 credits × target factor (Earth 1, Moon 2, distant 5); returns have at least factor 2. Recovery refunds paid hardware only at `20% + 80% × exp(-distance/(0.3 × Earth radius))`, by great-circle distance from the launch complex. Tech/affordability checks run before launch mutations, including for loaded craft. Simulation event evaluation happens every physics step and on rails propagation; SOI milestones also observe intermediate rails transitions. Milestones: first Earth orbit (20 science / 15,000 credits), first Moon landing (50 / 30,000), first Saturn entry (150 / 100,000), with +5 reputation in career. Science mode receives only science. Part-test and rescue contracts are deferred.

- **D-015 Communications**: Network difficulty defaults on in Science/Career and off in Sandbox. Settings can override it and independently allow full disconnected-probe control; world saves preserve the resolved difficulty. Three Earth stations (Coastal Launch Complex, Ochre Plateau, Dawn Reach) rotate with Earth and each rate 2 Tm. Antenna ratings are metres in the playable universe, unscaled across presets: Thread 500 km/direct, Lattice 50 Mm/relay, Arcwatch 5 Gm/relay, Horizon 500 Gm/relay. Pair range is the geometric mean; strength is smoothstep of remaining range fraction. Multi-source Dijkstra minimizes negative log strength, yielding the strongest product route to Earth, with relay-only forwarding and sphere occlusion by every celestial body. Graphs refresh at 4 Hz of simulation time or topology changes. A disconnected probe retains SAS attitude hold (directional modes fall back to stability assist), receives zero throttle/manual input, and cannot stage; crew retains local authority. Light time is informational (one-way, summed path length / real c), not delayed input execution. Network-enabled science sends one science point/second at full strength, multiplied by route strength, up to the existing antenna credit fraction. Interrupted data credit and queued jobs survive saves; rails catch-up is capped to 0.25 s per update rather than assuming connectivity through unobserved warp intervals. Power draw, terrain radio shadows and antenna deployment are abstracted. New relay parts enter the existing cost-based energy research tiers.
- **D-015 Experimental LAN co-op**: opt-in main-menu mode, Node/ws authoritative rooms with four players, standard-scale sandbox and in-memory lifetime. One 50 Hz shared World step, 10 Hz deltas, ~30 Hz inputs; one controller per vessel, independent FIFO pad/runway queues, minimum requested warp including spectators with whole-fleet safety clamps. At 1× clients predict only their own vessel, reconcile recent fixed steps and smooth corrections; remote poses interpolate 100 ms behind with body-ephemeris compensation. Topology changes remain server-authoritative. No automatic save/load or career mutations in network mode; trusted LAN hosting and low latency are the prototype scope.
- **D-015 Expedition parts**: Added 59 original parts with explicit expansion research tiers so the existing catalogue keeps its original research placement. Fuel cells automatically consume stack-fed liquid fuel and oxidizer only for electrical storage headroom; isotope generators continuously supply charge in the physics integrator. Radial engines/fuel cells may draw from their host stack without bypassing decouplers. Passenger cabins use command-module crew capacity with `controllable: false`, allowing crew transfer while requiring independent flight control. Cargo/service bay doors share the gear toggle and persist `bayOpen`; this avoids adding a separate flight control. Powered rover wheels use W/S forward/reverse while landed, A/D steering and B brakes. Methalox and nuclear engines follow the existing abstract fuel resource model. Radiators and ladders are explicitly visual hardware; active cooling/climbing and bay aerodynamic shielding remain future work.
- **D-015 Surface resources / ISRU**: Regolith is a dense (2.5 kg/L), vessel-wide resource. Its recoverable concentration is a seeded, continuous body-fixed noise field with polar enrichment, independent of terrain LOD and universe scale; nonsolid bodies return zero. Burrow/Quarry drills require solid-ground landing and a completed two-second deployment. Foundry recipes preserve all feedstock mass (kerolox O/F 2.56 by mass, or monopropellant); a transfer manifold fills vessel-wide product tanks, including stack tanks, without changing engine crossfeed rules. A shared event-based solver advances deployment, tank-boundary throttling and EC exhaustion analytically in physics and landed rails. Each machine has an isolated process core and integral 8 W/K radiator; its temperature follows an exact exponential, separately from hull aerothermal heating. Surveys are an explicit instrument action in a bound orbit within 10 degrees of polar and above terrain/atmosphere; results are global per-body saved flags. ISRU is assigned explicitly to discovery tiers 1–3 so pre-existing technology assignments do not move.
- **Tutorial practice isolation (2026-10-04)**: Each lesson starts a deterministic Standard-scale sandbox at the default epoch using public scenario helpers. The original program snapshot and craft are restored on exit; autosave, quicksave/load and remembered-craft persistence are suspended during practice. Completion checkmarks use a separate versioned local-storage key and require every goal without Skip. Original mentor Flight Director Ama Okafor guides eight lessons. F1 help remains available manually; its first-flight auto-display is suppressed during tutorials.
- **D-015 Surface scatter**: Render-only deterministic cube-face cells stream around the camera below 3 km above shared terrain. Instance matrices store metre-sized cell offsets; resident cell centers are rotated and rebased in JavaScript float64 before a float32 texture upload. Medium draws stones within 256 m; High adds vegetation within 1024 m; Low allocates no scatter. Earth vegetation follows the shared terrain's climate color and slope (water, desert, snow and the launch plateau excluded); steep/high land uses rocks. Rocks use a steep size distribution with rare 2–4 m boulders; Titan stones are 0.3× size. Generation yields between candidates and obeys both time and cell budgets. Assets and sub-metre terrain detail normals are procedural, with no sim collision added for decorations.
- **D-015 Flight data / map tools**: Detailed telemetry lives in main's persisted left HUD dock, with independently configurable sections. Prediction functions remain DOM/three.js-free in `sim/orbit/readouts.ts`; the game adapter samples shared future terrain and body rotation. Impact uses bounded conic sampling plus explicit periapsis sampling and a root solve, without atmospheric forces. Porkchop cells are estimates; click-to-plan requires the existing encounter refinement to succeed before replacing nodes. Map gizmo axes use the same maneuver frame as simulation.
- **D-015 Input / settings**: Persist physical-key bindings separately from settings so partial maps migrate against defaults. Context conflict checks allow editor/EVA reuse while flagging common shortcuts active in EVA. Standard gamepad stages require a 0.75-second hold and reconnect latching. Settings retain the existing version-1 storage keys with added defaults. Flight planet-effect changes use main's snapshot/rebuild path; pipeline-only effects update without restarting simulation. GameAudio subscribes to the settings store and releases its subscription on disposal.
- **D-015 First-play UX**: Flight HUD uses a single left dock with toggle chips (state in `wsp.hud.dock.v1`) instead of fixed panels; help overlay seen-flag `wsp.help.seen.v1`; editor craft persisted in `wsp.craft.v1` for Continue. New Game deletes the global quicksave slot. Stage numbers everywhere use the sim convention (highest fires first). Kestrel's tall tank became two starter tanks (same propellant) so every mode has a launchable stock rocket.
